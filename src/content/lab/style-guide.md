This was the place where I tried to make the invisible parts of a site visible: spacing rules, typography voices, color systems, interface patterns, and the logic beneath them.

It matters to this rebuild because it holds the right instinct. I did want a design system. I just buried that instinct inside too much architecture.

The current portfolio keeps that energy, but in a much smaller shape:

- fewer page types
- clearer tokens
- theme folders without the pressure to ship theme switching immediately
- stronger defaults instead of endless options
