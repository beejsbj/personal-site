Guided journaling where code owns everything that must not fail, and a companion model only does what models are good at.

A practice is a Markdown file: a title, a time, and a set of questions. Four come built in, for the morning, the evening, midweek, and the week. The engine sends the prompts and saves my replies word for word into Markdown entries, keeping the companion's words apart from mine.

Sending, dating, and capturing are plain code. The model writes an opener, talks, and drafts reflections. If no model can be reached, the journal keeps working without those.
