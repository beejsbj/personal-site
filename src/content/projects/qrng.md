## Two deliberately different worlds

The Lottery App uses a bold, graphic interface inspired by Persona 5. The Roulette App moves in the opposite direction: a darker, neon-lit bar atmosphere built around an animated SVG wheel.

Both began as demos for QRNG-driven interactions. The current versions preserve the selection, spin, and result flows as self-contained web simulations, without depending on the original wallet and contract infrastructure.

## What the pair explores

- themed interfaces that make a technical idea easier to approach
- responsive interaction patterns across phone and desktop layouts
- CSS and SVG animation used as part of the product language
- the same underlying concept expressed through two distinct visual systems
