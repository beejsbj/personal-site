## A place to practice layout

Layout Garden was a hands-on exercise in building adaptive, flexible layouts that respond to different viewport sizes. I made it during my time at Perpetual Education, using CSS Grid and Flexbox to work through different compositions.

The layouts connect to a foundational design system using CSS custom properties and design tokens. That let me adjust spacing, color, and type without having to rewrite each layout.

## What stayed with me

The useful part was making the layouts work together, not just making one screen look good. A shared system gave me room to keep experimenting while still keeping the pieces consistent.

This is an archived arcade project. The screenshot and source preserve the original work; the old interactive garden is not running inside this portfolio.
