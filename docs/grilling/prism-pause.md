# Prism Portfolio Pause

Status: paused.

The prism portfolio is the second layer of the personal site, not the base-site build. It is blocked by `BJS-39`, which must define the base personal-site content model and finish line before `BJS-42` can build the first usable base slice.

## Current Boundary

- The base site comes first.
- The prism is an outer/second layer around the base portfolio.
- The prism should not drive the base content model.
- `BJS-42` explicitly excludes the prism overhaul.

## Resolved Prism Decisions

- Visitors initially experience the site as a normal portfolio.
- The normal portfolio is happening inside the prism.
- The first reveal is curiosity-driven, not a forced timed intro.
- The exit affordance is the `Prism Lure`: alive, catchable, playfully evasive, and generous.
- Catching the lure triggers a camera pull-back, revealing the portfolio as a prism face.
- Outside-prism movement is fixed face-to-face travel, not free flight.
- The prism has six complete faces.
- The six faces are visual skins over the same portfolio structure, not separate content modes or story worlds.

## Current Six Lenses

1. Default
2. PE site
3. Persona 5 style
4. Jazz style
5. Roulette app style
6. Xpay 2 style

## Corrected Non-Goals

- Do not treat the six faces as creature/story sides.
- Do not create a separate clay-creature side.
- Do not make the prism taxonomy override the base site.
- Do not start implementation before the base content model is decided.

## Resume Point

When the base site exists, resume by defining how the six visual skins share one content/component structure and what design-system inputs each skin needs.
